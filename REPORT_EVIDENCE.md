1. Learner profile + topic + objective
2. Assessment Agent diagnosis: readiness, strengths, gaps and prerequisites
3. Personalized 9-stage Learning Path
4. Teaching Agent deep lesson with multiple sections
5. Practice Agent with hints and challenge
6. 20-question quiz
7. Evaluation & Feedback with score and concept-level performance
